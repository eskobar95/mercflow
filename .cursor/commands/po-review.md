# /po-review

**Usage:** `/po-review <notion-feature-request-url>`

Run Phase 1 of the PO Orchestrator on a Feature Request.

## What it does
1. Reads the Feature Request page from Notion
2. Writes the 10 structured discovery questions to the page
3. Sets Status to "Q&A Pending"

## Instructions
Read and follow `.cursor/skills/po-orchestrator/SKILL.md`, then execute **Phase 1: Discovery** on the provided Notion URL.

The feature request URL is: $input
